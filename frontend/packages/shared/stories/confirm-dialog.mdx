# ConfirmDialog

Reusable controlled confirmation composer for destructive actions. Consumers
supply the title, body, confirm verb, and pending verb; visibility remains
consumer-owned and closes only when `onOpenChange(false)` is requested.

## Token Audit

`ConfirmDialog` owns composition rather than raw styling. Its surface and action
colors come from the shared `DialogContent` and `Button` primitives.

### Layout and state

| Contract               | Source                               | Value                                |
| ---------------------- | ------------------------------------ | ------------------------------------ |
| Confirmation width     | `DialogContent` confirmation variant | `w-150` / 600px                      |
| Content maximum height | `DialogContent` confirmation variant | `max-h-60` / 240px                   |
| Pending state          | Confirm button                       | Disabled with spinning `Loader2`     |
| Footer layout          | `DialogFooter`                       | Stacked below `sm`, inline from `sm` |
