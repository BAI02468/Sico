# Studio Autosave Status

Persistent feedback for edit-mode Studio autosave. It replaces the manual Save action and keeps failures or version conflicts visible until resolved.

## API

<Controls />

- `status` — queue lifecycle state.
- `valid` — whether required Basic Info can be persisted.
- `onRetry` — explicit retry for transient failures.
- `onDiscard` / `canDiscard` — targeted cleanup for a permanently failed upload.
- `onConflict` — explicit reload/review action for version conflicts.
