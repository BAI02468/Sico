# Switch

Boolean control from shadcn `base-nova` using
[`@base-ui/react/switch`](https://base-ui.com/react/components/switch). Its
checked, unchecked, invalid, focus, and disabled treatments are driven by Base
UI data attributes and ARIA selectors, so both controlled and uncontrolled
usage share the same styles.

## Upstream Audit

Shadcn restyle of `base-nova/switch`.

### Token swaps

| Upstream class                                                         | SICO replacement                                                              |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `data-checked:bg-primary`                                              | `data-checked:bg-switch-track-fill-selected`                                   |
| `data-unchecked:bg-input`                                              | `data-unchecked:bg-switch-track-fill-rest`                               |
| `bg-background`                                                        | `bg-switch-thumb-fill`                                                        |
| `focus-visible:border-ring` / `focus-visible:ring-ring/50`             | `focus-visible:border-focus-rest` / `focus-visible:ring-focus-rest/50`        |
| `aria-invalid:border-destructive` / `aria-invalid:ring-destructive/20` | `aria-invalid:border-input-stroke-error` / `aria-invalid:ring-focus-error/20` |
| `data-[size=default]:h-[18.4px]`                                       | `data-[size=default]:h-switch-default-height` (exact 18.4px token)            |
| `data-[size=default]:w-[32px]`                                         | `data-[size=default]:w-8`                                                     |
| `data-[size=sm]:h-[14px]`                                              | `data-[size=sm]:h-3.5`                                                        |
| `data-[size=sm]:w-[24px]`                                              | `data-[size=sm]:w-6`                                                          |
| `translate-x-[calc(100%-2px)]` (default)                               | `translate-x-3.5` (14px)                                                      |
| `translate-x-[calc(100%-2px)]` (small)                                 | `translate-x-2.5` (10px)                                                      |

The focus and validation swaps are intentional semantic-role choices, not
compatibility renames. SICO's cross-control contract names neutral keyboard
focus (`focus-rest`), a validation border (`input-stroke-error`), and an invalid
focus ring (`focus-error`) explicitly. `ring` currently bridges to `focus-rest`,
and `destructive` currently shares danger-500 with `focus-error`, but the invalid
border deliberately resolves to danger-700. Keeping the generic upstream aliases
would therefore obscure role ownership and collapse the border/ring distinction;
token priority selects the explicit semantic roles even where terminal values
currently match.

### API contract

The public API matches upstream: `SwitchPrimitive.Root.Props` plus the
upstream `size?: "sm" | "default"` prop. Base UI state selectors and
accessibility semantics are unchanged. The decorative thumb adds only the stable
`data-testid="switch-thumb"` test hook required when no semantic role exists.
The explicit `React.JSX.Element` return type and narrow ESLint annotations for
Tailwind v4 tokens are compile-time project integration only; neither changes
the runtime API.

### Deleted from upstream

| Deleted                               | Reason                                                                                 |
| ------------------------------------- | -------------------------------------------------------------------------------------- |
| `dark:data-unchecked:bg-input/80`     | SICO has no active dark theme; the component rest token owns the unchecked state.       |
| Dark invalid border/ring variants     | SICO has no active dark theme; semantic input-error/focus-error tokens own validation. |
| Dark checked/unchecked thumb variants | SICO has no active dark theme; the component thumb token is shared across states.      |
